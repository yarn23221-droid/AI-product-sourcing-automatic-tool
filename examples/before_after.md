# 수작업 대비 소요시간·정확도 비교 (기록 틀)

이 문서는 결과가 아니라 **기록 틀(템플릿)**입니다. 아래 표의 값은 실제로 수작업과 자동화 버전을
직접 돌려보면서 측정한 뒤 채워 넣으세요. 측정하지 않은 값을 그럴듯하게 지어내지 마세요 —
빈칸으로 두거나 "[측정 필요]"로 남겨 두는 편이 정직한 포트폴리오 기록입니다.

## 측정 방법 제안

1. 같은 상품 목록(예: 가상 상품 10~15건)을 두 가지 방식으로 각각 처리한다.
   - **수작업**: 엑셀을 열어 사람이 직접 최저가 계산, 가격차이 계산, 타겟가 판단, 수요 사유 분류를 수행
   - **자동화**: `python src/main.py` 한 번 실행
2. 각 방식에 걸린 시간을 스톱워치로 잰다.
3. 결과물을 비교해 계산 오류(수식 실수, 최저가 오판 등) 개수를 센다.
